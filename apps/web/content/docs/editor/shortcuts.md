---
title: Keyboard shortcuts
description: Common shortcuts for navigating and editing the canvas.
---

Shortcuts can vary slightly by OS and browser. Use **⌘** on macOS and **Ctrl** on Windows/Linux unless noted.

## Navigation

| Action | Shortcut |
| --- | --- |
| Pan | Drag background / trackpad |
| Zoom | Scroll / pinch |
| Fit view | Editor zoom control (UI) |
| Open nested diagram | Node action / double-click (when enabled) |

## Selection & edit

| Action | Shortcut |
| --- | --- |
| Select | Click |
| Multi-select | Shift + click (when supported) |
| Delete selection | Delete / Backspace |
| Undo | ⌘/Ctrl + Z |
| Redo | ⌘/Ctrl + Shift + Z |

## Clipboard (when enabled)

| Action | Shortcut |
| --- | --- |
| Copy | ⌘/Ctrl + C |
| Paste | ⌘/Ctrl + V |
| Duplicate | ⌘/Ctrl + D |

## Collaboration & chrome

| Action | Where |
| --- | --- |
| Share | Top bar |
| Export | Top bar / menu |
| History | Top bar |
| Inspector | Selection |

If a shortcut conflicts with the browser, use the on-canvas controls instead.

## Accessibility tips

- Prefer zoom controls over extreme trackpad pinch if precision matters.
- Keep node titles short so keyboard-focused reviews stay readable.
- Use flows to present paths without manually hunting edges.
