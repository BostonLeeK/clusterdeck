This guide takes you from sign-up to a saved, shareable diagram.

## 1. Create an account

1. Open the app and go to **Sign up**.
2. Enter email and password (or use the available auth options).
3. Confirm your session — you land on **Projects**.

If you already have an account, use **Sign in**.

## 2. Create a project

On **Projects**:

1. Click **New project**.
2. Optionally start from a **template**.
3. Give it a name when prompted, or rename later from the project card menu.

The editor opens with an empty (or template-filled) canvas.

## 3. Build something useful

Typical first session:

1. Add a few **nodes** from the palette (apps, databases, external services).
2. Connect them with **edges**.
3. Group related nodes if needed.
4. Open a node’s **child diagram** when a subsystem needs its own canvas.
5. Add **tags** or a named **flow** if you want visual filters later.

See [Canvas overview](/docs/editor) and [Nodes](/docs/editor/nodes).

## 4. Save and collaborate

- Changes sync for collaborators in realtime when they are on the same diagram.
- Use **Share** to invite people or create a public link.
- Use the project menu for **Duplicate**, **Rename**, **Save as template**, or **Export**.
